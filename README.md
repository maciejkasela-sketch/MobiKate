# Mobilność Kasi

Aplikacja PWA: mobilność, siła i brzuch pod aerial silks. Działa offline, dane zapisują się w telefonie.

## Publikacja na GitHub Pages
1. Nowe publiczne repozytorium na github.com.
2. Add file → Upload files: wgraj całą zawartość tego folderu (index.html, sw.js, manifest.webmanifest, foldery icons i fonts).
3. Settings → Pages → Deploy from a branch → main, / (root) → Save.
4. Po chwili aplikacja jest pod adresem https://LOGIN.github.io/NAZWA-REPO/

## Instalacja na iPhonie
Otwórz adres w Safari → Udostępnij → Do ekranu początkowego → Dodaj.

## Aktualizacja
Po podmianie plików zmień w sw.js nazwę CACHE (np. kasia-v3), żeby telefony pobrały nową wersję.
